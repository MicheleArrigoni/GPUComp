# Lecture 2 study guide

`lecture2_cuda_study.tex` is the English study guide integrating the lecture 2
slides and pages 5-8 of the handwritten notes. Original figures are in `images/`.

Compile from the project root:

```powershell
.tools/tectonic/tectonic.exe --outdir assignment2/final assignment2/latex/lecture2_cuda_study.tex
```

Output: `assignment2/final/lecture2_cuda_study.pdf`.
The first build may require an internet connection for LaTeX packages.
The CUDA examples are educational and have not been executed on a GPU.
